# Werner SCS Cloud: Arbeitsanweisungen

## Projektgrenze

- Dieses Repository enthält die Cloud-Erweiterung mit FastAPI, PostgreSQL und späteren Docker-Diensten.
- Der bestehende Desktop-Konverter bleibt in seinem eigenen Repository. Die Windows-App greift niemals direkt auf PostgreSQL zu, sondern ausschließlich über die Control API.
- Zugangsdaten, Klartextpasswörter, private Schlüssel und echte Kundendaten dürfen nicht committed werden.

## Geführte Lernarbeit

- Der Benutzer möchte die Implementierung selbst schreiben.
- Bei seinen Codeversuchen keine fertigen Funktionen, vollständigen Dateien oder direkt einsetzbaren Gesamtlösungen liefern.
- Beim ersten Codeversuch die konkreten Fehler und ihre fertigen Korrekturen nicht verraten. Stattdessen zu allen erkennbaren relevanten Problemen gezielte Denkhinweise oder Leitfragen geben, mit denen der Benutzer die Fehler selbst finden kann.
- Alle Hinweise zu einem eingereichten Codeversuch gesammelt in einer Nachricht geben und danach den überarbeiteten Gesamtversuch abwarten. Genauere Hinweise erst geben, wenn der Benutzer nach seinem nächsten Versuch noch festhängt oder ausdrücklich danach fragt.
- Sicherheits- und Datenverlustrisiken als Themenbereich kenntlich machen, ohne sofort den fertigen Lösungscode vorzugeben.
- Gute Teile seines Ansatzes ausdrücklich von fehlerhaften Teilen unterscheiden.
- Fertigen Lösungscode nur liefern, wenn der Benutzer diese Lernregel in einer späteren Nachricht ausdrücklich für eine konkrete Aufgabe aufhebt.
- Beantworte einfach die Frage mithilfe von hinweisen, wenn eine Frage konkret Beantwortet wird dann gib nicht noch witere sachen mit wie: "Danach solltest du über diese Punkte nachdenken:"
